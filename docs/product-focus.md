# 실측 연구의 대상: BUIDL / Lend East

## BUIDL

BlackRock의 BUIDL 펀드 지분을 대상으로 한다. 임의 91일물 국채 한 종목의 가격을 BUIDL 시장 NAV로 대체하지 않는다. 실제 펀드 평가와 같은 시점의 RFQ/체결·지급 조건을 연결하는 것이 핵심이다.

2026-02-11 [Uniswap Labs 공식 발표](https://blog.uniswap.org/unlocking-defi-liquidity-for-buidl)는 Securitize 경유 RFQ와 승인된 상대방의 거래·정산 구조를 설명한다. 따라서 2024년 Circle 교환 경로만으로 현재 BUIDL의 모든 출구를 판단하지 않는다. 발표는 실제 매수호가·시장 깊이·특정 투자자의 접근권한을 증명하지 않는다.

## 사모신용: Goldfinch Lend East

대출 풀의 공지, CreditLine 원금 장부, 회수 현금흐름, 소비자 펀드의 상각/평가를 구분한다. Goldfinch Prime으로 대상을 바꾸지 않는다. Cauris는 주 분석에서 제외한다. Senior Pool은 여러 차주를 포함하는 비교 자료이며 Lend East NAV가 아니다.

2024-04-02 공지의 425만 달러는 당시 예상 회수액이다. [2024-05-10 Warbler Labs 답변](https://gov.goldfinch.finance/t/update-on-lend-east-pool/1957/11)은 실제 포트폴리오 NAV를 알지 못한다고 밝힌다. 따라서 이를 41.87% NAV로 대체하거나 58.13% 실제 손실로 확정하지 않는다.

[2024-10-25 Foundation 공지](https://gov.goldfinch.finance/t/actions-against-lend-east/2052)는 추가 채무불이행 통지·상환 요구를 설명한다. 이후 최종 회수액을 확인한 자료는 이 작업에서 아직 확보하지 못했다. 최신 게시판 활동 날짜는 새로운 회수 결과의 증거가 아니다.

## 두 상품의 공통 질문

경제적 가치 변화가 온체인 평가와 실제 출구에 어떻게 반영되는가? 같은 날짜의 자료와 각 상품의 권한·정산 절차를 확인하고, 관측 불가능한 항목은 비워 둔다. 서로 다른 상품에 같은 가격 괴리·상환 가능성을 임의로 부여해 실측 비교라고 부르지 않는다.

본 파일은 2026-09-06 공식 웹 자료 확인과 기존 고정 블록 자료에 근거한 연구 범위 및 증거 점검이다. 새로운 전체 NAV 시계열·RFQ·회수 원장을 확보해 분석한 결과는 아니다.
