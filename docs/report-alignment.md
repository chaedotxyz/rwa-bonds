# 보고서 대응 및 반드시 구분할 주장

현재 코드의 구조는 3장의 가설·선정·검증·파라미터와 4장의 B-1/B-2/B-3 비교에 대응한다. 보고서 초안의 숫자나 강한 결론을 그대로 인증하지 않는다.

| 보고서 내용 | 현재 대응 | 보고서 작성 시 처리 |
|---|---|---|
| B-1 국채 합의 경로 | 담보 PfC + 합의 기대비용 + 지분자본 별도 | 특정 조건의 닫힘. 국채는 합의 경로밖에 없다는 주장은 사용하지 않음 |
| B-2 NAV 45일+120일 지연 | 선언한 grace/선형 상각 경로 | 실제 Goldfinch NAV 반영 지연 관측으로 쓰지 않음 |
| B-3 같은 신용 대조 | B-2와 매 표본 동일 PfC | 합의 비용만 다른 경제적 대조 |
| 국채 0%, 신용 61.7%, 대조군 0% | 독립 LHS 결과 | 원본 수식·분포 미확보. 원본 비율은 재현 미확인 |
| 지분 1/3 가격 전액이 CoC | 자본 K와 기대 지출 분리 | 자본장벽과 손익비용의 구분 필요 |
| 세 경로 모두 확정 유지 | B-2는 정상 합의 전제, 나머지는 합의 경로 반사실 | 네트워크를 실행해 확인했다고 쓰지 않음 |
| 국채는 스테이킹 비용이 닫음 | LTV·매입비만으로도 닫힐 수 있음 | 어떤 항이 구간을 닫았는지 분리 |

기본값에서 B-1은 국채 마크 괴리가 담보 할인(LTV)을 넘지 못하므로 PfC 자체가 음수다. 따라서 "국채는 지분비용 덕분에만 닫혔다"는 설명으로 이 결과를 인용하면 안 된다. 낙관적 NAV 차액 상한과 지분 비용을 비교한 열은 보조적인 상한 대조다.

B-2는 가치가 낮은 청구권을 매입해 오래된 높은 NAV로 빠져나갈 수 있다는 조건부 출구를 갖는다. 이 호가·자격·NAV·재원은 실제 Lend East 또는 FIDU에 대해 입증되지 않았다. 예상 회수액 425만/1,015만은 유용한 손실 앵커이나 실제 펀드 전체 NAV와 같지 않다. default exposure_share=1은 순수 신용 풀의 대용이다.

B-3는 합의 손실률을 0으로 바꾸는 대조에서도 함께 계산한다. 이때 결과가 달라지면 제재손실 가정에 민감한 결론이라는 뜻이다. "항상 닫힘"으로 일반화하지 않는다. 통제 지분 1/3 자체를 자동 슬래싱으로 처리하지 않는다.

## 보고서에 가져갈 수 있는 문장

“국채 담보 경로, 신용 NAV 지연 경로, 동일 신용의 합의 비용 대조군을 구분했다. 명시한 자산·출구·비용 가정 아래에서 PfC, CoC, 손익분기점을 재현하고, 실제 관측과 미확인 실행 조건을 분리했다. 따라서 결과의 열림·닫힘은 선언한 경제적 시나리오에 대한 판정이며, 실제 공격 성공이나 모든 경로의 안전성에 대한 판정은 아니다.”

## 실증으로 강화하기 위해 남은 자료

1. 원본 3.2 노트의 수식·파라미터 범위·분포·표본 생성 코드.
2. 특정 소비자 계약과 역사 배포 버전의 실제 평가식·권한·출구·재원.
3. 실제 투자자에게 체결 가능한 매입가격·수량과 상환/대출 실행 조건.
4. 신용 부실을 알게 된 시점과 개별 대출 상각이 소비자 NAV에 반영된 시점.
5. 구체적 공격 행위에 맞는 합의/지연 비용. 지분 확보 가격을 곧바로 손실로 두지 않는 비용 근거.

빈 항목을 숫자로 꾸며 넣지 않았고, 원본 61.7%를 얻기 위해 파라미터를 보정하지 않았다.
